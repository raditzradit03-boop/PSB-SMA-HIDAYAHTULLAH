PROFIL PROJECT

Informasi pendaftaran dalam satu tempat

Website ini merupakan contoh project Sistem Informasi Penerimaan Siswa Baru (PSB). Website menyediakan halaman beranda, profil sistem, kontak/form pendaftaran, serta galeri dokumentasi.

Dengan adanya menu navigasi, pengguna dapat berpindah dari satu halaman ke halaman lainnya melalui hyperlink. Tabel digunakan sebagai contoh penyajian data calon siswa, sedangkan form digunakan untuk menggambarkan pengumpulan informasi pendaftar.

Tujuan pembuatan

  • Memudahkan pengguna menemukan informasi pendaftaran.
  • Menyajikan contoh data calon siswa dalam bentuk tabel.
  • Menyediakan form contoh untuk mengisi data pendaftaran.
  • Menerapkan hyperlink ant halaman HTML.
